# 開盤配對助手（Chrome 插件）

人盯盤、人按買入；插件負責**看盤提示、擋違規、一鍵切邊填金額、記帳**。插件不會自己下單，也不需要私鑰。

## 規則（fish 2026-10-29）
1. 開盤後**第一分鐘內**，哪一邊賣價先跌到 **0.40**，用市價買第一張，金額固定 **$5**。
2. 之後另一邊賣價跌到「扣兩次手續費後仍賺錢」的價位以下（第一張 0.40 → 第二張上限 0.56），買**同樣股數**。
3. 抱到結算拿 $1。同一場只做一組；不准放大金額；不准加買第一張那一邊。

## 安裝
1. Chrome 網址列打 `chrome://extensions`，右上角打開「開發人員模式」。
2. 按「載入未封裝項目」，選這個資料夾 `pair_plugin`。
3. 在插件清單按「詳細資料」→「擴充功能選項」，填你的 Polymarket 錢包地址（0x 開頭，個人頁可複製；公開地址，只用來讀你自己的成交）。每張金額預設 $5、觸發價 0.40。
4. 打開任何一場 BTC／ETH／SOL 5 分鐘盤，右上角會出現深色面板。

## 用法
- 面板顯示兩邊賣價、開盤後秒數、現在該做什麼。可以買的那一邊會變綠。
- **按空白鍵**（或面板上的綠色大按鈕）：插件自動切到規則指定的那一邊、填好金額、按下買入。
  - 第一張：若下單模式是「1-Tap」，直接點 $5；否則填 $5 按「買入」。
  - 第二張：要買同樣股數，金額每次不同，請把下單模式切到**市價**（有金額欄的那個）。
- 你自己用滑鼠按「買入」或 1-Tap 金額按鈕也一樣會被檢查：不符合規則、金額超過上限、加買同一邊、開盤超過一分鐘才開第一張，都會被擋下並顯示原因。
- 面板下方有本場部位和今日統計（場數、成對、補不到、損益），結算後自動記。

## 已知限制
- 下單模式「市價」的金額欄和「買入 Up」按鈕要登入後才看得到，2026-10-29 只在未登入狀態測過切邊和 1-Tap 按鈕偵測；登入後第一次使用請先用 $1～$5 試一筆。
- 成交紀錄來自 Polymarket 公開介面，買完約 2～5 秒才會更新；這段時間插件會擋下再次買入。
- Polymarket 改版可能讓按鈕偵測失效，失效時插件會擋下並提示「找不到按鈕」，不會亂按。
