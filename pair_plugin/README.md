# 開盤配對助手（Chrome／Comet 插件，人工模式＋練習模式 v0.5）

人決定第一張的時機；插件負責**第二張自動算同樣股數並掛限價單、擋違規、記錄每一場**。插件只在你按鍵或點按鈕時才下單，不需要私鑰。

## 練習模式（預設開啟，不花錢）
- 面板最上面的藍色勾選框「練習模式（不花錢、不會下單）」。勾著的時候：
  - 空白鍵／U／D 照樣用，但**不碰頁面上的下單按鈕**，改用當下真實盤口模擬成交：
    - 第一張照賣單一路往上吃到 $5，算平均價和股數，手續費照官方公式另扣。
    - 第二張照賣單一路吃到同樣股數（直接買），收手續費。
  - 你自己點頁面上的買入按鈕會被擋下，避免不小心真的下單。
  - 收盤後照真實贏家算損益，面板顯示「今日練習」統計，和真實交易分開記。
  - 不需要填錢包地址。
- 取消勾選要按「確定」才會切到真實模式（紅色），之後空白鍵會真的下單。
- 限制：第二張的模擬成交要停在那一場的頁面才看得到；離開頁面後不會再判斷成交，但收盤後一樣會自動結算。

## 規則（fish 2026-10-30，v0.4 起）
1. **第一張：你決定**什麼時候買、買哪一邊。只能用市價（1-Tap 或市價單），金額固定（預設 $5），不准用限價、不准放大。
2. **第二張：也是你決定**什麼時候補。面板第三格即時顯示「現在補對面，扣兩張手續費後賺幾 %」（綠色賺、紅色虧），價格一動就跟著變。看到滿意的數字按空白鍵，插件**直接買**（市價）對面同樣股數，不留掛單。
3. 抱到結算拿 $1。同一場只做一組；不准加買第一張那一邊。

## 安裝
1. Chrome 網址列打 `chrome://extensions`，右上角打開「開發人員模式」。
2. 按「載入未封裝項目」，選這個資料夾 `pair_plugin`（舊版已載入的話，按插件卡片上的重新整理箭頭）。
3. 插件「詳細資料」→「擴充功能選項」：填錢包地址（公開地址，只用來讀你自己的成交）、第一張金額、目標利潤、第一張最晚秒數。
4. 打開任何一場 BTC／ETH／SOL 5 分鐘盤，右上角會出現深色面板。

## 用法
| 按鍵 | 什麼時候 | 插件做什麼 |
|---|---|---|
| 空白鍵 | 還沒買第一張 | 市價買**較便宜的那一邊**（下跌的那邊），金額固定 |
| U／D | 還沒買第一張 | 市價買 Up／Down（指定邊） |
| 空白鍵 | 第一張成交後 | **直接買**對面，股數和第一張一樣，不留掛單 |

- 面板三格：Up 賣價｜Down 賣價｜第三格。
  - 第一張前：第三格顯示兩邊相加。
  - 第一張後：第三格顯示「現在補 Down（或 Up）+x.x%，每股 +x.x 分」，即時跳動。
- 第三格的 % 是照盤口「買滿同樣股數」的平均價算的，最便宜那一檔賣單不夠時也準。
- 市價按金額買，價格一動股數會差一點；兩邊差 3% 以內都算成對，不用補零頭。
- 你自己用滑鼠下單也一樣會被檢查：第一張用限價、金額超過、加買同一邊、第二張價格高於對面賣價或股數超過，都會擋下並說明原因。
- 你自己在頁面上手動掛的第二張限價單，沒成交想重來：先在頁面上取消舊掛單，再按面板上的連結。
- 面板顯示幣價和「離開盤線多遠」。開盤線 = 開盤前 60 秒 Chainlink 平均，和官方算法相同。要在開盤前 1 分鐘內打開頁面才算得出來；晚打開時面板不顯示，但收盤後紀錄會用官方開盤價補上。
- 設定頁可以下載每場紀錄（CSV），用來分析你的進場判斷。第一欄 `mode` 是 sim『練習』或 live『真實』。內容有：
  - 第一張按下當下的兩邊賣價、前 60 秒走勢
  - 當下幣價、開盤線、離線距離（美元、bps『萬分之一』、標準化距離；正 = 幣價站在你買的那邊）
  - 成交價、第二張掛單價（上限）和實際成交均價、贏家、損益

## 已知限制
- 2026-10-30 在未登入狀態測過：切換 1-Tap／市價／限價、選邊、填限價和份額（頁面顯示總計正確）、讀取送出內容。**登入後還沒測**，第一次用請先用 $5 試一場。
- 登入後送出按鈕的文字如果不是「交易」或「買入 Up／Down」，插件會顯示「找不到送出按鈕」，不會亂按。
- 成交紀錄來自 Polymarket 公開介面，成交後約 2～5 秒才更新；這段時間插件擋下再次下單。
- 對面已經低於掛單價時，限價單會立刻吃單成交，這時要付手續費（面板會先提醒）。
